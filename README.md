# CredWise – Loan Approval System

CredWise is Machine Learning-based Loan Approval System developed as my first minor project in supervised learning. The project explore financial data through Exploratory Data Analysis (EDA) and applies multiple classification algorithms to predict loan approval outcomes.

## Key Features

- Exploratory Data Analysis (EDA) and data preprocessing.
- Implementation of supervised machine learning algorithms.
- Feature scaling using StandardScaler.
- Model training and testing using Train-Test Split.
- Performance evaluation and comparison of classification models.

## Machine Learning Algorithms

- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes
- Logistic Regression

## Technologies & Libraries

- Python
- Jupyter Notebook
- Pandas
- Numpy
- Matplotlib
- Seaborn
- Scikit-learn

## Objective

To understand and implement supervised machine learning techniques for a real-world financial use case: predicting loan approval decisions based applicant data.

**Project Type** : Machine Learning - Minor Project
